Colar um contrato no chat de uma IA para pedir um resumo leva segundos. Avaliar se aquele contrato tinha dados pessoais de clientes, informações sigilosas ou segredos comerciais deveria levar um pouco mais.

## Onde a LGPD entra

A Lei Geral de Proteção de Dados não proíbe o uso de inteligência artificial. Ela exige que o tratamento de dados pessoais tenha **finalidade, base legal, necessidade e segurança**. Quando um colaborador envia dados de clientes a uma ferramenta não homologada, a empresa pode estar descumprindo todos esses princípios de uma só vez.

## Perguntas que toda empresa deve responder

1. Quais ferramentas de IA estão **autorizadas**?
2. Os dados enviados são usados para **treinar o modelo** do fornecedor?
3. Onde os dados ficam **armazenados** e por quanto tempo?
4. Quem tem **acesso** ao histórico de conversas?
5. Existe **registro** de quem usou e para quê?

## Regras práticas para os colaboradores

- ✅ Usar apenas as ferramentas homologadas, com a conta corporativa;
- ✅ Anonimizar dados sempre que possível;
- ✅ Revisar o resultado antes de usar: a IA erra;
- ❌ Não enviar CPF, dados de saúde, dados bancários ou senhas;
- ❌ Não enviar documentos classificados como confidenciais sem autorização.

## Governança é o caminho

Bloquear tudo apenas empurra os colaboradores para contas pessoais. O caminho é oferecer **ferramentas seguras**, definir **políticas claras**, **treinar** as pessoas e **monitorar** o uso.

> A pergunta não é "podemos usar IA?", e sim "como usar IA com segurança e dentro da lei?".
